# Brand assets

`custom_integrations/sextant/` holds the icon and logo in the layout the
[home-assistant/brands](https://github.com/home-assistant/brands) repository
expects (`icon.png` 256x256, `icon@2x.png` 512x512, `logo.png`, `logo@2x.png`,
transparent background). Home Assistant fetches integration artwork from
that repository only, so to have the icon show on the Integrations page and
in HACS, copy this folder into a fork of brands and open a pull request.
The source drawing is generated by a small script; regenerate rather than
hand-edit if the mark changes.
